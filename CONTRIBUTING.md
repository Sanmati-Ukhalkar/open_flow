# Contributing to open_flow

Thanks for your interest in contributing.

## Run locally

```bash
git clone https://github.com/Sanmati-Ukhalkar/open_flow.git
cd open_flow
npm install
npm run dev
```

## Submitting a pull request

1. Create a branch from `main`.
2. Keep your change focused and small.
3. Include tests for behavior changes when test infrastructure exists.
4. Open a PR with a clear title, summary, and verification steps.

## Coding conventions

- Prefer small, readable functions and focused commits.
- Follow existing naming/style patterns in the repository.
- Avoid unrelated refactors in the same PR.
